# Privacy, permissions, and compliance audit

Reviewed 6 November 2026 against the checked-in source and pubspec.lock. This is a source/dependency audit, not a network-traffic certification or a submitted store declaration.

## Data flows and evidence

| Function | Evidence | Processing and persistence |
|---|---|---|
| Microphone | lib/audio/microphone_service.dart | record.hasPermission at listening start; mono PCM16 stream, 44.1 kHz, 2048-sample analysis windows. No start-to-file call. |
| Pitch/rhythm | lib/audio/pitch_detector.dart, note_segmenter.dart, phrase_analyzer.dart; lib/transcription | Local signal analysis and quantization. Phrase frames buffered in memory (up to the phrase limit); resulting note event metadata can be saved. |
| Saved music | lib/services/composition_storage_service.dart | App documents directory; compressed MXL with MusicXML plus JSON containing notes, timing, confidence, title, lyrics and score settings. File modification timestamps support the library/imports. |
| Preferences | lib/services/settings_service.dart | shared_preferences stores detection/practice settings on-device. |
| Playback | lib/services/score_playback_service.dart, metronome_service.dart | Bundled SoundFont and local synthesis; audioplayers BytesSource may create cached synthesized WAV files. These are not microphone recordings. |
| Import | native MainActivity.kt / AppDelegate.swift / SceneDelegate.swift; incoming_file_service.dart | User-opened local score files copied into private temporary import directories. |
| Share | home_screen.dart | User explicitly chooses an OS sharing destination for an MXL file. Destination providers apply their own policies. |
| Screen awake | screen_awake_service.dart | wakelock_plus used during active transport; no personal data. |

No developer network endpoint, HTTP client, analytics, advertising, crash-reporting, account system, purchases, advertising identifier, or tracking code was identified in the application. XML DTD URLs are notation declarations, not a network fetch path in this importer. Generic network playback capabilities in audioplayers are not used: this app supplies generated bytes. External sharing and OS backups are separate possible data transfers and are disclosed in the prepared policy. Local data is not promised to be encrypted, and retained exports/backups are not promised to be erased by uninstalling.

## Dependency inspection

`dependency-audit.json` records the actual resolved native plugins and their manifest declarations. Runtime plugins: audioplayers, record, shared_preferences, path_provider, share_plus (with package_info_plus), wakelock_plus; Android also has JNI support. Dart archive/xml and SoundFont synthesis run locally. No ad/analytics SDK is present in the lockfile. Integration-test tooling is a development dependency; Flutter also generates registration for its native helper. The production `lib/main.dart` does not load the test binding, test navigation, capture client, or Flutter driver service. Native helper registration alone adds no screenshot upload or network flow. Validate that the submitted build uses `lib/main.dart`; the final native plugin inventory includes that helper rather than assuming dev dependencies are excluded from native packaging.

Plugin capabilities alone are not evidence of collection. Audited native permission declarations include RECORD_AUDIO from record_android; audioplayers uses local sound bytes in this app. Final release merged-manifest and embedded privacy inspection is required where builds are available, with results captured separately.

## Permissions and denial

Android app manifest requests RECORD_AUDIO. There is no main-manifest INTERNET permission (debug/profile add it for Flutter tooling), storage, contacts, location, or camera access. Normal process-text package visibility is retained. No broad storage permission is needed for app-private files or user-shared URI imports.

iOS has the explicit purpose string: “Sheet Music Rookie uses your microphone to detect musical notes and help create sheet music.” Deployment target remains 15.0. iPhone/iPad support, bundle identifier, and signing team are unchanged.

TranscriptionEngine.initialize defaults to autoStart=false. Listening starts on user action. Denial/start failures set MicrophoneStatus.unavailable; the UI explains microphone unavailability and leaves editing available. The unavailable card explains permission recovery and has a Retry button; editing remains usable. Enable access in system Settings and tap Retry. No background recording mode is enabled. Tests cover algorithmic processing; actual sung audio quality and system permission denial on physical devices are manual release checks.
